## 📖 About

Welcome to **Learning Journey**, my personal space for growing as a programmer and software engineer.

This repository holds the code I write, the problems I solve, the notes I take, the experiments I try, and the projects I build along the way. Some of it will be neat, some of it will be messy, and that's the point. It's a record of learning in progress, not a gallery of finished work.

> 💬 **The main idea:** *Everything I learn, practice, build, and improve goes here.*

<br/>

## 🧠 My Learning Approach

I don't have a perfect system, but these are the habits I try to follow:

1. **Understand first, memorize never.** If I can't explain why the code works, I haven't learned it yet.
2. **Practice over passive reading.** I write the code myself, even when the solution looks obvious.
3. **Start simple, then go deeper.** Get the basic version working first, then improve it.
4. **Treat mistakes as lessons.** Bugs and wrong answers teach me more than code that works on the first try.
5. **Revisit and refine.** Coming back to an old solution and making it better is real progress.
6. **Stay consistent.** Small, regular effort beats occasional bursts.
