## 👋 About

Welcome to my **Learning Journey**, a personal space where I keep track of my growth as a programmer and software engineer.

This repository holds the code I write, the problems I solve, the notes I take, the experiments I run, and the projects I build along the way. Some of it will be clean and some of it will be messy, and that's fine. It's a record of learning in progress, not a showcase of finished work.

The repository is meant to grow with me. As I pick up new languages and concepts, new folders will appear and old ones will get better.

---

## 🎯 Why I Created This Repository

- **To stay consistent.** A single place for all my practice keeps me accountable.
- **To track my growth.** Looking back at old code shows me how far I've come.
- **To learn by doing.** Reading about a concept is one thing, but writing the code is how it sticks.
- **To build a habit of documenting.** Explaining what I learn, even in short notes, helps me understand it better.
- **To have a foundation.** Over time, this will become a solid base of practice, projects, and reference material.

## 🧠 My Learning Approach

I don't have a perfect system, but these are the principles I try to follow:

1. **Understand first, memorize never.** If I can't explain why the code works, I haven't learned it yet.
2. **Practice over passive reading.** I write the code myself, even when the solution seems obvious.
3. **Start simple, then go deeper.** Get the basic version working first, then improve it.
4. **Mistakes are part of it.** Bugs and wrong answers teach me more than code that works on the first try.
5. **Revisit and refine.** Coming back to an old solution and improving it is real progress.
6. **Stay consistent.** Small, regular effort beats occasional bursts.
