## 👋 About This Repository

This repository holds every C++ program I wrote while going through the **Introduction to Algorithms (Batch 8)** course.

Everything is organised **module by module**. Each `Module N` folder contains the solutions for one topic of the course, and every file is named after what it does, so you can open a file and immediately know what it solves.

> 📅 **Upload plan:** I upload **one module every day**, so this repo grows day by day. The progress table below shows what is already uploaded.

## ⚡ Algorithm Cheat Sheet

| Algorithm | Time Complexity | Best used for |
|:----------|:---------------:|:--------------|
| 🌊 BFS | `O(V + E)` | Shortest path in unweighted graphs, level order traversal |
| 🏝️ DFS | `O(V + E)` | Components, cycle detection, grid exploration |
| 🚀 Dijkstra (optimized) | `O((V + E) log V)` | Single source shortest path, non-negative weights |
| ➖ Bellman-Ford | `O(V · E)` | Shortest path with negative weights, negative cycle detection |
| 🌐 Floyd-Warshall | `O(V³)` | All-pairs shortest path |
| 🔗 DSU (path compression + union by size) | `~O(α(N))` | Connectivity, cycle detection, Kruskal |
| 🌲 Kruskal MST | `O(E log E)` | Minimum spanning tree |
| 🎒 0/1 Knapsack (DP) | `O(N · W)` | Choose items under a capacity limit |
| 🧬 LCS (DP) | `O(N · M)` | Longest common subsequence of two strings |
| ✂️ Merge Sort | `O(N log N)` | Divide and conquer sorting |

## ▶️ How to Run a Program

Every file is a standalone C++ program. Pick any file and run it like this:

```bash
# 1. Compile
g++ "Module 2/bfs.cpp" -o bfs

# 2. Run (Linux / macOS)
./bfs

# 2. Run (Windows)
bfs.exe
```

Most programs read their input from the standard input, for example the number of nodes and edges followed by the edge list.

## 🧭 How to Read the Code

- 📄 **File names describe the goal.** For example `detect_cycle_in_directed_graph_using_bfs.cpp` does exactly what it says.
- 🔀 **Same problem, different approach.** Some modules keep more than one version of a solution side by side (naive vs optimized, recursion vs memoization vs bottom-up), so you can compare them.
- 🧱 **Each module builds on the previous one.** Follow the roadmap above from top to bottom if you are learning.
